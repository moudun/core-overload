System Overload / Core Overload — Project Version Log
=====================================================

V1.3  (2026-09-11)
  ================ 大改版：从「线性 18 房」升级为「分支路线 + 过载博弈 + 局外永久解锁」 ================
  - 新增 autoload：Overload（过载核心）、RunSave（局内断点存档）；
    EventBus / GameState / MetaState / Lang / Settings / RunDirector 全面升级到 V1.3 契约
  - 分支路线图（RouteDirector）：
      * 每个区块生成一张 7–9 节点的有向无环图（DAG），起点到 Boss 至少存在 2 条有效路线
      * 逐层链接并保证后一层每个节点至少 1 条入边；Boss 前一层 55% 概率把战斗房升级为精英房
      * 保证房型：每个区块必出 商店 / 维修 / 骇入 各 1 间（不足则挤掉中后段随机节点）
      * 按深度加权抽房型 + 每区块出现次数上限（RoomDB.weighted_pool / max_per_biome）
      * 清房后不直接进下一间，而是弹「系统拓扑图」由玩家选路（点击或 1/2/3 键）
  - OVERLOAD 过载系统（本版核心博弈杠杆）：
      * 0–100 连续值，5 段状态：稳定 0-39 / 高负载 40-69 / 危险 70-89 / 临界 90-99 / 崩溃 100
      * 过载不是纯 debuff：高段位给 掉落率 +5/12/25%、金币 +20/40%、细胞 +25%、伤害 x1.08–1.45
      * 危险段起敌人伤害 +10%；≥90% 进入 OVERDRIVE（部分武器额外强化）
      * 按住 V 主动泄压（牺牲射击与移速）；自然衰减 3.2/s；局外「能源工程」提供抗性与泄压加成
      * 崩溃（满 100）：随机触发 设备断电 / 电涌 / 核心灼烧 / EMP，返还部分资源并回落到 28
      * 房间异常规则 heat_mult 会放大过载积累：过载是「房间 × 构筑 × 主动操作」的三方博弈
  - 11 类房间（RoomDB 数据驱动，RoomManager 状态机分发）：
      * combat  战斗房：双波次（60%/40%），掉金 + 能量，38%+掉落运气触发三选一奖励
      * elite   精英房：全员精英（2.5x HP / 1.5x 伤害 / +8 护盾），必掉奖励（偏奖励池）
      * treasure 宝藏房：战斗 + 宝箱（E）：+30 金币 + 卷轴三选一，但触发 6 只精英反噬
      * repair  维修房：无战斗，进场即解锁；每区块中继补满治疗瓶
      * shop    黑市：4–5 个随机货位（武器/治疗/协议/卡/能量），价格受诅咒卡折扣影响
      * lab     实验室：矿物信标，与「武器实验室」解锁线呼应
      * glitch  故障房：22 秒内按正确顺序修复 3 个管线节点；按错掉血 + 刷故障体 + 序列重洗
                       成功给 能量 +45 / 细胞 +4 / 金币 +15 并追加二选一；超时转入战斗
      * harvest 收割房：30 秒限时清怪，达成率 0–3 倍结算金币与细胞（越贪越危险）
      * hack    底层骇入：走到终端按 E 进入「KERNEL HACK」竖版射击小游戏，产出底层源代码
      * boss    区块 Boss（冷却巨兽 / 墓场守望者 / 主脑本体）
      * tutorial 教学模拟房（新手关，不占路线节点、不进随机池）：
                     进入即封闭并弹出目标面板，6 步操作训练
                     移动 → 射击(命中假人 3 次) → 翻滚 → 换武器 → 泄压 → 系统技能
                     训练假人不还手不死亡；开始时发放副武器，让 Q 换武器有意义
                     vent 步先灌 45 点过载，让玩家直观看到泄压效果
                     仅在新档首局自动出现；主菜单「训练关卡」可随时重玩（不推进存档）
                     完成后不写断点、不占房间序号，直接进入本区块第一次路线图选点
  - KERNEL HACK 竖版射击小游戏（局内嵌入式，非独立项目）：
      * 玩家操控数据包向上渗透：3 波入侵进程 → 防火墙 mini-boss
      * 自机双管自动射击；敌机 5 种（含带弹幕的射手与精英）+ 放射弹幕 Boss
      * 护盾制失败判定（初始 3 + 骇入强化等级）；通关给金币/细胞，并按分数产出源代码
      * 与主流程完全通过 EventBus（hack_requested / hack_started / hack_finished）解耦，
        玩家进入时主战场暂停，结束后回到房间继续
  - 局内断点存档（RunSave）：
      * 只在「安全状态」写盘：清空房间后 / 路线图选点前；战斗中不写，避免半死状态读档
      * 主菜单「继续 Run」显示 区块/深度/HP 摘要，读档还原 HP、经济、武器、协议、卡、过载等全量状态
      * 死亡 / 通关 / 主动放弃时清除；单存档槽位（user://run_save.json）
  - 局外双货币成长（MetaState / MetaDB）：

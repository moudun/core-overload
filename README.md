# Core Overload

像素风 2D **房间推进式动作 Roguelite**，Godot 4.4.1 / GDScript。

你是一颗会翻滚的核心。杀穿三大区块、十八间房，把失控的主脑本体回收。
每清空一间房，右侧的门就会变绿；一路向右，直到区块尽头的 Boss。

核心骨架对标 **Dead Cells**：房间推进 + 翻滚无敌帧 + 双武器槽 +
卷轴三选一构筑 + 细胞兑换的局外永久成长。

**全部美术与音效均由代码程序化生成**（`scripts/util/PixelArt.gd` 逐像素绘制贴图，
音效为运行时合成的 `AudioStreamWAV`），仓库零外部素材依赖，克隆下来就能跑。

## 运行方式

- 引擎：Godot **4.4.1 stable**（官方 Windows 版）
- 打开：Godot → Import → 选择 `project.godot` → 运行（F5 / ▶）

## 操作

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| 鼠标移动 | 瞄准 |
| 鼠标左键（按住） | 自动射击 |
| `Shift` / `空格` | **翻滚闪避**（0.26s 无敌帧，可穿弹幕） |
| `Q` | 切换主 / 副武器 |

| `E` | 交互（开宝箱 / 商店购买） |

| `R` | 结算后重新开始 |
| `ESC` | 返回主菜单 |

## 玩法循环

1. **每区块固定 6 间房**，顺序为：战斗 → 战斗 → 宝藏 → 战斗 → 商店 → **Boss**。
2. 踏入房间即锁门；清空全部敌人后门变绿解锁，走进右侧出口推进下一间。
3. 战斗房给金币，宝藏房给**过载卷轴三选一** + 细胞，商店可花金币买武器 / 维修 / 卷轴。
4. 打完 Boss 进下一区块。**共 3 区块（18 间房）**，击杀主脑本体即通关。
5. 核心 HP 归零 → 结算；本局攒下的**细胞 1:1 兑换科技点**，回主菜单的「收集者」永久强化。

## 敌人与 Boss

4 种基础敌人（无人机自爆 / 重装高伤 / 疾行高速 / 远程喷吐）+ 精英变体（掉细胞）。
区块缩放倍率 **1.0 / 1.35 / 1.80**。

| Boss | 区块 | HP | 机制 |
| --- | --- | --- | --- |
| 冷却巨兽 COOLANT TITAN | 冷却水道 | 260 | 蓄力冲撞（0.8s 预警）→ 撞墙眩晕 1.5s 输出窗口；≤50% 追加 12 向放射弹幕 + 召唤疾行者 |
| 墓场守望者 GRAVEKEEPER | 服务器墓场 | 420 | 瞬移 → 扇形弹幕 → 召唤喷吐者；≤40% 攻速 ×1.5 |
| 主脑本体 THE CORE MIND | 主脑核心 | 600 | 三阶段：螺旋弹幕 / 激光阵列 / 追踪弹；≤33% 狂暴冲撞 |

**诅咒宝箱**：战斗房有概率出现，按 `E` 开启可得卷轴 + 30 金币，但会引来 **6 只精英**的过载反噬。

## 收集者（局外永久成长）

细胞 1:1 兑换科技点，5 项永久升级（存档 `user://meta.json`）：

| 升级 | 上限 | 效果 | 科技点 |
| --- | --- | --- | --- |
| 核心装甲 | Lv3 | 初始 HP +10 / +20 / +30 | 20 / 45 / 80 |
| 相位引擎 | Lv2 | 翻滚冷却 -15% / -30% | 30 / 60 |
| 启动资金 | Lv2 | 开局金币 +30 / +60 | 25 / 50 |
| 备用弹匣 | Lv1 | 开局副武器槽携带随机武器 | 70 |
| 应急血清 | Lv1 | 每区块治疗瓶充能 +1 | 50 |

## 项目结构

```
project.godot              # 项目配置（6 个 Autoload）
scenes/
├── MainMenu.tscn          # 主菜单
└── main_game.tscn         # 主游戏场景
scripts/
├── autoload/
│   ├── EventBus.gd        # 全局信号总线
│   ├── GameState.gd       # 单局状态 + 成长公式（伤害/冷却/移速）
│   ├── MetaState.gd       # 局外成长（科技点 / 永久升级 / 存档）
│   ├── RunDirector.gd     # Run 总控：区块与房间序列
│   ├── Lang.gd            # 中英双语词条表
│   └── Settings.gd        # 设置持久化
├── data/
│   ├── WeaponDB.gd        # 武器数值表（数据驱动，加一条即新增武器）
│   └── EnemyDB.gd         # 敌人数值表 + 区块缩放 + Boss 配置
├── run/
│   ├── RoomFactory.gd     # 程序化房间生成（地板/墙/门/障碍柱）
│   └── RoomManager.gd     # 单房间状态机 BUILD→LOCKED→COMBAT→CLEARED→TRANSITION
├── world/MainGame.gd      # 主控：房间编排 / 转场 / 特效 / 音效 / 伤害飘字
├── entities/
│   ├── CorePlayer.gd      # 玩家核心：移动 / 翻滚无敌帧 / 双武器 / 治疗瓶 / 暴击
│   ├── Enemy.gd           # 入侵者：四种 AI（近战追击 / 远程风筝）+ 精英
│   ├── Bullet.gd          # 玩家子弹（直射 / 追踪 / 贯穿）
│   ├── EnemyBullet.gd     # 敌方子弹
│   ├── LootCard.gd        # 统一掉落物（卡牌 / 武器 / 卷轴 / 金币 / 细胞）
│   └── bosses/            # CoolantTitan / Gravekeeper / CoreMind
├── ui/
│   ├── HUD.gd             # 顶栏 / Boss 血条 / 横幅 / Toast / 教程 / 结算
│   └── ScrollChoice.gd    # 过载卷轴三选一
├── menu/                  # 主菜单 / 语言设置 / 收集者面板
└── util/PixelArt.gd       # 程序化像素贴图生成
```

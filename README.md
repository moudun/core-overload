# Core Overload

像素风 2D **分支路线式动作 Roguelite**，Godot 4.4.1 / GDScript。

你是一台被唤醒的**核心机体**。在三大区块的**系统拓扑图**上自己选路，一路向下骇入、收割、超频，
最后把失控的主脑本体回收。

V1.3 的核心变化：房间不再是固定顺序，而是**分支路线图**；新增全局**OVERLOAD 过载**博弈杠杆、
11 类房间、嵌入式**底层骇入**竖版射击小游戏、局内**断点存档**，以及「科技点 / 底层源代码」
**双货币局外成长**。新档第一次开局会先进入**教学模拟房**，逐步带出全部操作。

**全部美术与音效均由代码程序化生成**（`scripts/util/PixelArt.gd` 逐像素绘制贴图，
音效为运行时合成的 `AudioStreamWAV`），仓库零外部素材依赖，克隆下来就能跑。

> 旧版已归档：`V0.1` 终端文字策略版、`V1.1` 波次防守版、`V1.2` 线性 18 房版。

- 引擎：Godot **4.4.1 stable**（官方 Windows 版）
- 打开：Godot → Import → 选择 `project.godot` → 运行（F5 / ▶）

## 玩法循环

0. **新档第一次开局**会先进入**教学模拟房**（`训练关卡` 也可在主菜单随时重玩）：
   6 步操作训练，逐步通过即完成，不影响存档进度。
1. 开局弹出**系统拓扑图**：当前区块的 7–9 个节点中挑一个进入（到 Boss 至少有 2 条路线）。
2. 进入房间后门锁死。战斗房分两波；清空后门变绿，走到右侧出口推进。
3. 清房时如果处于危险状态，**过载会带来额外金币/细胞/掉落**——但随时可能崩溃。
4. 清房后回到拓扑图继续选路；打完区块 Boss 进入下一区块，**共 3 区块**。
5. 死亡或通关都会结算：本局**细胞 1:1 兑换科技点**，骇入/Boss/区块产出**底层源代码**，
   回主菜单「收集者」消费。
6. 游戏中随时 `ESC` →「保存并退出」写入**断点存档**，下次从主菜单「继续 Run」接上。

## OVERLOAD 过载系统（本版核心）

过载不是纯 Debuff，而是**玩家可以主动踩红线的收益杠杆**。

| 区间 | 状态 | 额外收益 | 代价 |
| --- | --- | --- | --- |
| 0–39 | 稳定 | — | — |
| 40–69 | 高负载 | 掉落率 +5%，伤害 ×1.08 | — |
| 70–89 | 危险 | 金币 +20%，掉落率 +12%，伤害 ×1.18 | 敌人伤害 +10% |
| 90–99 | 临界 | 金币 +40%，细胞 +25%，掉落率 +25%，伤害 ×1.32，**OVERDRIVE** | 敌人伤害 +10% |
| 100 | **崩溃** | 返还部分资源 + 过载遗物 | 随机触发 断电 / 电涌 / 核心灼烧 / EMP，回落到 28 |

- 自然衰减 3.2/s；按住 `V` 以 30/s 主动泄压（受局外「能源工程」与冷流场加成）。
- 房间异常规则的 `heat_mult` 会放大过载积累——过载是「房间 × 构筑 × 主动操作」的三方博弈。

## 11 类房间

| 房型 | 内容 |
| --- | --- |
| **教学模拟** tutorial | 新手关：6 步操作训练（移动/射击/翻滚/换武器/泄压/技能），训练假人不还手不死亡，完成即开出口。不占路线节点，只在「新档首局」或主菜单「训练关卡」出现 |
| **战斗房** combat | 双波次（60%/40%），掉金币与能量；38%+掉落运气触发三选一奖励 |
| **精英房** elite | 全员精英（2.5× HP / 1.5× 伤害 / +8 护盾），必掉奖励 |
| **宝藏房** treasure | 战斗 + 宝箱（`E`）：+30 金币 + 卷轴三选一，但引来 **6 只精英**反噬 |
| **维修房** repair | 无战斗，进场即解锁；每区块中继补满治疗瓶 |
| **黑市** shop | 4–5 个随机货位（武器/治疗/协议/卡/能量），受诅咒卡折扣影响 |
| **实验室** lab | 矿物信标，与「武器实验室」解锁线呼应 |
| **故障房** glitch | 22 秒内按正确顺序修复 3 个管线节点；按错掉血 + 刷故障体 + 序列重洗；超时转入战斗 |
| **收割房** harvest | 30 秒限时清怪，达成率 0–3 倍结算金币与细胞（越贪越危险） |
| **底层骇入** hack | 走到终端按 `E` 进入竖版射击小游戏，产出**底层源代码** |
| **Boss** | 区块 Boss（冷却巨兽 / 墓场守望者 / 主脑本体） |

每个区块**保证出现** 黑市 / 维修 / 骇入 各一间；Boss 前一层 55% 概率把战斗房升为精英房。

### 教学模拟房（新手关）

- 进入即封闭房间并弹出目标面板（`训练 1 / 6`），第 1 步就先教移动；全部由
  `EventBus.tutorial_step` 驱动 HUD，语言切换即时刷新。
- 六步：**移动 → 射击（命中假人 3 次）→ 翻滚 → 换武器 → 泄压 → 系统技能**。
  每步完成才解锁下一步；`vent` 步会先灌一段过载，让玩家看到泄压的实际效果。
- 开始时发放一把副武器（教学补给），`Q` 换武器与 `1/2` 双槽因此有意义。
- 完成后不写断点存档、不占房间序号，直接进入本区块第一次**路线图选点**。
- 入口：新档首局自动进入；主菜单「**训练关卡**」可随时重玩（不推进存档）。

## 底层骇入（KERNEL HACK）

局内嵌入式竖版射击小游戏，不是独立项目：

- 玩家操控数据包向上渗透：**3 波入侵进程 → 防火墙 mini-boss**。
- 自机双管自动射击；敌机 5 种（含弹幕射手与精英），Boss 有放射弹幕 + 瞄准射击。
- **护盾制失败判定**（初始 3 + 「骇入强化」等级）；通关给金币/细胞，并按分数产出源代码。
- 与主流程完全通过 `EventBus`（`hack_requested` / `hack_started` / `hack_finished`）解耦：
  进入时主战场暂停，结束后回到房间继续。

## 构筑三件套

- **协议模块**（12 种，I → II → III 升级）：重复获取即升级，最多同时装备 3 条；
  包含 汲能 / 相位 / 磁场 / 超频 / 装甲 / 电容 / 链式反应 / 处决 / 泄压 / 吸血 / 冰场 / 回收装置。
- **过载卡**（8 张）：双刃即时强化，带持续房间数。
- **标签套装**（7 系）：OVERCLOCK / CRYO / ARC / VOID / SALVAGE / FORTIFY / PRECISION，
  每系 2 / 4 / 6 层档位解锁被动；**最高档决定 `R` 键系统技能**。

## 房间异常规则（12 种）

高热 / 冷流场 / 自带护盾 / 蜂群 / 重装甲 / 浓雾 / 停电 / 电涌池 / 冷却池 / 反射镜 / 重力错乱 / 超频区。

## 美术与界面

全程序化，零外部素材。

### 玩家机体

不再是「一颗球」——初始机体就是一台 34×34 的**装甲机体**（`PixelArt.player_core_tex()`）：

- **八边形装甲舱体**：rim / shell_lit / shell / hull 四层明暗 + 接缝十字分件
- **四角梯形推进器喷口**：沿对角线布置的 4 个 bell，带喷口内壁与高热区
- **中央反应堆核心**：core_a / core_b / core_c 三层同心亮芯

机体之上挂了两个子节点（`entities/CorePlayer.gd`）：

- **反应堆光晕**——Additive 混合 + 呼吸缩放；泄压时转冷蓝，无敌帧时压暗
- **推进器尾焰**——按移动 / 翻滚方向反向喷射，静止时隐藏并带随机抖动

### 界面主题

`scripts/ui/UITheme.gd` 提供一整套可复用控件样式，HUD 与所有面板共用同一套视觉语言：

| 能力 | 说明 |
| --- | --- |
| `panel()` / `panel_flat()` / `panel_slice()` | 9 宫格渐变面板（带 1px 描边）、直角面板、自定义边距面板 |
| `bar_slot()` | 条槽底：深底 + 圆角 + 描边，用于 HP / 过载 / Boss / 武器槽 |
| `hairline()` / `corner_brackets()` | 1px 细分隔线、四角装饰角标 |
| `icon()` | 11 种矢量图标：HP / 过载 / 翻滚 / 技能 / 护盾 / 金币 / 细胞 / 能量 / 源代码 / 深度 / 警示 |
| `glow_label()` | 辉光 + 描边字号，用于标题与横幅 |

### HUD

纯代码构建（`ui/HUD.gd`），无 `.tscn` 依赖：

- **大气层**：全屏暗角 vignette；HP < 35% 时叠加脉动**红警暗角**
- **顶栏**：顶部渐隐条 + 分隔线 + 四角角标；HP 条与过载条共用「条槽 + 顶部高光 + 25/50/75% 分段刻度」
- 属性四联、治疗瓶点位、双武器槽（武器配色芯片 + 激活态高亮）、环形 CD（内嵌矢量图标）
- 资源行（金币 / 细胞 / 能量 / 源代码，右对齐）、标签条（左侧竖脊 + 表头）、
  Boss 血条（高光 + 刻度）、全宽横幅条、带左侧色条的 Toast、结算面板
- 教程面板带进度条，仍由 `EventBus.tutorial_step` 驱动，切语言即时刷新

### 美术图鉴

`tests/_shot.gd` 会额外抓一张美术图鉴（`00_art_sheet.png`），把机体、光晕、尾焰、
全部图标铺开显示，方便一眼核对。
